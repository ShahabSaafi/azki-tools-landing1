# جعبه‌ابزار عملیات ازکی — راهنمای دیپلوی روی Vercel

## ساختار پوشه
```
azki-tools-landing/
├── index.html          ← صفحه اصلی (لندینگ، تم تیره، شبیه صفحه اصلی موبایل)
├── tools/
│   ├── sheba-matcher.html
│   ├── health-premium-calculator.html
│   ├── insurance-excel-validator.html
│   ├── asia-claims-report.html
│   ├── dey-claims-report.html
│   ├── alborz-claims-report.html
│   └── asemari-claims-report.html
└── vercel.json
```

## دیپلوی (ساده‌ترین راه)
1. برو به https://vercel.com/new
2. پوشهٔ `azki-tools-landing` را (کل پوشه) بکش و بنداز.
3. Deploy را بزن — چند ثانیه بعد لینک عمومی آماده است.

## دیپلوی با CLI
```bash
npm i -g vercel      # فقط بار اول
cd azki-tools-landing
vercel --prod
```

## اضافه کردن ابزار جدید
1. فایل html ابزار را در `tools/` بگذار (تم تیره، طبق دیزاین‌سیستم مشترک: نوار بالا با دکمهٔ بازگشت، دایره‌های شماره‌دار، دراپ‌زون).
2. در `index.html`، داخل آرایهٔ `CATEGORIES`، یک آیتم به `tools` دستهٔ مناسب اضافه کن:
```js
{ icon: "📊", title: "عنوان کوتاه", href: "tools/file.html", size: "lg" }
```
فیلد `size:"lg"` اختیاری است — تایل را بزرگ‌تر و برجسته‌تر نشون می‌ده (برای ابزار مهم/پراستفادهٔ آن دسته).
سه دسته از پیش تعریف شده: `اکانت و فروش` / `صدور` / `خسارت`، هرکدام با رنگ اختصاصی خودشون (در `CATEGORY_COLORS`). دستهٔ خالی خودش placeholder «به‌زودی» نشون می‌ده.

3. ذخیره و دوباره دیپلوی کن (`vercel --prod` یا drag & drop).
